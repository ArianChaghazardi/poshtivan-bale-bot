# ربات مرکزی بله پشتیوان | Poshtivan Bale Master Bot Server

سرویس مستقل و پرسرعت پایتون بر پایه asyncio و aiohttp جهت مدیریت متمرکز و دو طرفه ربات بله برای افزونه پشتیوان وردپرس.

## ویژگی ها

* اتصال چند وبسایت به صورت همزمان به یک اکانت کاربری در بله
* ارسال آنی اعلانات چت آنلاین و تیکت ها به مدیران متصل
* پشتیبانی کامل از پاسخگویی دو طرفه با ریپلای (Reply) مستقیم روی پیام ها در پیام رسان بله
* ثبت خودکار اتصال و همگام سازی آنی وضعیت با REST API وردپرس
* پایگاه داده محلی SQLite با نگاشت دقیق پیام ها به شناسه چت و تیکت
* عدم نیاز به ابزارهای جانبی پیچیده و سازگاری کامل با سرورهای ایران

## نحوه راه اندازی و اجرا

۱. وابستگی های پایتون را نصب کنید:
```bash
pip install aiohttp
```

۲. تنظیمات فایل `config.json` را بررسی کنید:
```json
{
    "bot_token": "YOUR_BALE_BOT_TOKEN",
    "bot_username": "poshtivanbot",
    "mode": "polling",
    "api_host": "127.0.0.1",
    "api_port": 8092,
    "bale_api_url": "https://tapi.bale.ai",
    "database_file": "bale_master.db"
}
```

۳. اجرای ربات:
```bash
python3 bot.py
```

## دستورات ربات در پیام رسان بله

* `/start` - معرفی ربات و شروع کار
* `/connect PST-XXXXXXXX` یا ارسال مستقیم کد سایت - اتصال سایت به اکانت بله
* `/status` - مشاهده لیست وبسایت های متصل با امکان قطع اتصال
* `/disconnect PST-XXXXXXXX` - قطع ارتباط یک وبسایت
* `/help` - راهنمای جامع استفاده
